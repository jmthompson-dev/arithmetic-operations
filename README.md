# Arithmetic Operations

This project demonstrates basic arithmetic operations in Python along with a fun ASCII art banner. The program is divided into two parts:

- **Part 1: Addition and Subtraction**  
  The user is prompted to input two numbers. The program then calculates and displays the sum and difference.

- **Part 2: Multiplication and Division**  
  The user is prompted to input two numbers. The program calculates and displays the product and quotient (with a check to avoid division by zero).

## Prerequisites

- Python 3.x must be installed on your system.

## How to Use

1. **Clone the Repository (if applicable):**

   ```bash
   git clone https://github.com/jmthompson-dev/arithmetic-operations.git
   ```

2. **Run the Program:**

   - Run:

     ```bash
     python add_subtract.py
     python multi_divide.py
     ```

3. **Follow the On-Screen Prompts:**

   - Enter the required numbers when prompted.
   - View the results, including the ASCII art banner and the computed arithmetic outputs.

## Project Structure

- `add_subtract.py` and `multi_divide.py`: Contains the source code for the arithmetic operations and the ASCII art banner.

## Features

- **Addition & Subtraction:** Computes and displays the sum and difference of two user-provided numbers.
- **Multiplication & Division:** Computes and displays the product and quotient of two user-provided numbers (with error handling for division by zero).
